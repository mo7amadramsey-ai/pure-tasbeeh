# حالة المشروع

## آخر ما تم
- كتابة مشروع Android كامل (Kotlin + Compose + DataStore): العداد، الأهداف، تبديل الأذكار بالسحب، الاهتزاز، الإحصائيات، الإعدادات، الوضع الليلي، وضع صارم بفاصل زمني، أيقونة تكيّفية.
- إضافة workflow لبناء APK تلقائياً عبر GitHub Actions.
- تم التحقق (الجلسة 2): البناء عبر GitHub Actions ينجح. لم يُجرَّب التطبيق على جهاز بعد.
- أُضيفت وثيقة التصور الكاملة في docs/VISION.md.
- (الجلسة 2) الوضع الصارم صار جلسة محدودة المدة: 1 إلى 10 دقائق، سقف مطلق 10 دقائق، مؤقت يظهر المتبقي وتنتهي الجلسة تلقائياً. لم يُنفَّذ بعد منع الإشعارات والتطبيقات الأخرى.
- بدأ نقاش الوضع الصارم (تثبيت الشاشة + عدم الإزعاج + إبقاء الشاشة مضاءة كاقتراح)، ولم يُعتمد بعد.

## لم يتم بعد
- آليات التركيز في الوضع الصارم (platform/focus).
- تصدير الإحصائيات واستيراد مكتبة الأحاديث JSON.
- خطوط Alexandria وCairo وInter.
- واجهة إنجليزية.
- Room بدلاً من DataStore للإحصائيات (اختياري).
- توسيع مكتبة الأحاديث (فيها حديث واحد، ويجب التحقق من أي إضافة).
- حسم القرارات الأربعة المعلقة في وثيقة التصور.
- اختبارات الاستمرارية والبطارية وأجهزة متعددة، وصفحة الإصدار والتوثيق.
